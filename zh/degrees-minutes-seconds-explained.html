度分秒怎么读、怎么算

度分秒是 60 进制，不是十进制。这不是一个记法上的细节——把 39°54′22″ 误当成 39.5422° 来用，纬度就差 0.363911 度， 在北纬 40° 附近是 40.4 公里。下面把三种写法、互转公式、 以及每一秒值多少米都算清楚。

角度与坐标更新于 2026年10月9日阅读约 7 分钟

同一个角的三种写法

写法示例进制使用场合
度分秒（DMS）39°54′22″N60 / 60 / 十进制秒控制点成果表、地形图、地籍资料
度分（DDM）39°54.3667′N60 / 十进制分导航设备、部分航海与航空资料
十进制度（DD）39.906111十进制GIS、GPS、程序接口、计算器

三者是同一个角的三种记法，与精度无关。它们的差别只在「角被切成了几段」： 度分秒把度切成分（1° = 60′）、再把分切成秒（1′ = 60″）， 所以 1° = 3600″；度分只切到分；十进制度不再切分。

互转公式与算例

度分秒 → 十进制度

十进制度 = 度 + 分 ÷ 60 + 秒 ÷ 3600

以 39°54′22″ 为例：54 ÷ 60 = 0.9， 22 ÷ 3600 = 0.006111…，相加得 39 + 0.9 + 0.0061111 = 39.9061111°， 即 39.906111°。南纬或西经在最后加负号。

十进制度 → 度分秒

度 = 取整数部分
分 = 取小数部分 × 60 的整数部分
秒 = 剩余小数 × 60

反算 39.906111°：0.906111 × 60 = 54.36666′， 取整得 54′；余下 0.36666 × 60 = 22.0″，结果回到 39°54′22″。整个往返过程中不需要任何查表。

反过来算也很重要。把 39.5422 当成十进制度读， 它对应 39°32′31.92″——小数部分 0.5422 度是 32.532 分， 不是 54 分 22 秒。两种读法相差 0.363911 度。 在北纬 40° 附近，纬度 1 度约 111 042 米，所以这个「读法问题」 是 40 409.6 米，约 40.4 公里的地理位置差。

一秒值多少米

判断精度时用得最多的一张表。纬度方向几乎恒定，经度方向随纬度急剧收缩：

读法上，只要记住「纬度 1″ 约 30 米，经度 1″ 约 30 米 × cos(纬度)」就能估： 北纬 40° 处 cos ≈ 0.766，30.8 × 0.766 ≈ 23.6 米，与表中实测的 23.753 米 相差不到 1%，用来口算精度够用。 1′ 是 1″ 的 60 倍，所以北纬 40° 附近 纬度 1′ = 1850.550 米。

度分秒的加减要借位

因为进制是 60，做加减时借位与进位都按 60 走，不能按 100：

39°54′22″ + 0°07′50″ = 40°02′12″
39°54′22″ − 0°07′50″ = 39°46′32″

第一条：22″ + 50″ = 72″ = 1′12″，进位 1′；54′ + 7′ + 1′ = 62′ = 1°02′， 再进位 1°；39° + 0° + 1° = 40°，得 40°02′12″。 第二条：22″ 减 50″ 不够减，从分借 1′（= 60″）， 82″ − 50″ = 32″，分变成 53′；53′ − 7′ = 46′，得 39°46′32″。 如果按十进制的习惯去借位（借 100 而不是借 60），秒会算成 72″， 规范化之后是 39°47′12″，比正确结果多了 40″。

抄录与读法错误清单

  • 把 DDMMSS 当十进制读。最常见的错误，代价见上文那 40.4 公里。
  • 分或秒写成 60 以上。39°60′00″ 不是合法写法， 它等于 40°00′00″；同样 39°54′60″ 等于 39°55′00″。软件遇到这种输入往往会静默接受并算出偏移的结果。
  • 方位字母与正负号重复。N 39°54′22″ 与 39°54′22″N 都是正纬度；写成 N -39°54′22″ 则自相矛盾， 不同软件的取舍不同，结果不确定。
  • 东经西经、南纬北纬配错。北京的经度是东经 116°， 如果按西经解释，点位会跑到太平洋东侧；纬度按南纬解释则落到南半球。 写成果表时把方位字母写全，是成本最低的保险。
  • 纬度与经度次序颠倒。国内资料常见「先纬度后经度」， 而部分国际数据源用「先经度后纬度」。看数值范围可以区分： 纬度不会超过 ±90，经度可以到 ±180。
  • 度分秒符号丢失。纯数字粘贴时 39 54 22 与 39.5422 在不同软件里可能被解释成不同的东西。 需要跨软件传递时，写明用哪种记法。

测绘中的其他角度单位

除了度与度分秒，还会遇到另外几种角度单位，换算时都经过「度」：

单位与度的关系使用场合
弧度（rad）1 rad = 57.295779513°程序接口、公式推导
百分度 / gon1 gon = 0.9°（1 周 = 400 gon）欧洲测量仪器、部分全站仪显示
密位（北约制）1 mil = 0.05625°（1 周 = 6400 mil）军用方位、火炮
密位（炮兵制）1 mil = 0.06°（1 周 = 6000 mil）部分国家炮兵体系

方位角与象限角的换算在测绘中也会频繁出现：象限角用 N 45°00′00″ E 这样的四象限格式，方位角用 0°–360° 的整圆格式。 两者之间的换算规则随象限不同，需要单独成表，本页不再展开。
