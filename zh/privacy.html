隐私政策

最后更新：2026 年 10 月 9 日 适用于本站所有页面

本站是一组计算器，关于隐私，最简短也最诚实的总结是这一句： 计算器在你的设备上运行，你输入的数字留在你的设备上。 没有账号、没有表单、没有上传、没有服务器端计算。本页用与站内其他部分一样的大白话， 解释为数不多的几个例外——一份 Web 服务器日志、一个需主动勾选的统计脚本，以及一个 localStorage 键。

一句话版本

  • 坐标、数值和粘贴进来的清单永远不会离开你的浏览器。 每一次换算、平差、面积与体积计算都由运行在你机器上的 JavaScript 完成。 计算器背后没有 API 调用，也没有任何服务器能看到你的输入。
  • 没有广告，没有广告联盟，没有跨站跟踪。任何页面都不加载第三方广告或社交脚本。
  • 统计需要主动勾选，且不使用 Cookie。只有一个统计脚本，而且只有在你点击 接受统计之后才会加载。它记录页面浏览量和使用了哪个工具， 不设置 Cookie，也不建立任何会跟着你的画像。
  • 只有一个 localStorage 键。写进你浏览器的唯一内容是 coordcalc-consent，用来记住你在横幅里做过的选择。你随时可以删掉它。
  • Web 服务器会保留普通日志。任何 Web 服务器都会： 你的 IP 地址、请求的页面、时间，以及浏览器的 User-Agent。 这些日志用于运维和保障站点安全，不用于画像。

什么永远不会离开你的浏览器

你输入计算器的所有内容，都由你已经加载好的这个页面处理。 横轴墨卡托级数、Vincenty 距离算法、最小二乘导线平差、鞋带公式面积求和、 以及 DXF 文件解析器，全都是文档里的 JavaScript。 当你把 43.642567, -79.387139 换算成 UTM 坐标， 或从 CAD 文件里读出顶点时，数据是从本地的文件选择框或文本框中读入，再写回同一个页面的。

整个流程中没有任何一步会把你的输入序列化后发往别处。你可以自己验证： 打开浏览器开发者工具，盯着网络面板，然后用任意一个计算器。页面、样式表和脚本加载完毕之后， 使用这些工具不会产生任何请求。页面打开后计算器还能离线使用， 而这只可能是因为没有任何数据要往返于服务器。

文件也是一样。DXF 坐标提取 用浏览器自带的 FileReader 接口读取你选中的文件，全程在内存中完成。 文件不会上传、不会排队、不会存储，关掉标签页就没了。

Web 服务器能看到什么

要把这个页面送达，Web 服务器就必须响应你的请求，因而会产生一条日志记录， 每个网站都是如此：请求的 URL、日期时间、你的 IP 地址、 你的浏览器愿意发送的来源页面，以及浏览器的 User-Agent 字符串。 这是标准做法，无法避免，也不是本站额外加的东西。

这些日志用于维持站点正常运转——错误率、失效链接、滥用流量—— 不会与你在计算器里做的任何操作相关联，因为本站从来收不到你在计算器里做了什么。 日志保存有限的一段时间后即删除。

统计，以及同意横幅

本站使用一个尊重隐私的统计脚本，用来了解哪些计算器有人用、哪些没人用， 好把力气花在有用的地方。该脚本不使用 Cookie：不设置 Cookie、不读取已有 Cookie、 不对你的设备做指纹识别，也不会跟到任何其他网站去。 它记录页面名称、事件（一次浏览、某个计算器被使用、某个外链被点击） 以及来源页面这类粗粒度信息。

你的选择会发生什么
接受统计 统计脚本在本次及以后的访问中加载。页面浏览量和工具使用事件会被计数。 你输入计算器的内容不在其中——事件只说明某个工具被用过，不包含你换算的是什么。
仅必要 Cookie 统计脚本在本次及以后的访问中都不加载。站点表现完全相同；你只是什么都没告诉我们。

在你做出选择之前，不会有任何统计请求发出——闸门是在脚本有机会加载之前就关上的， 而不是之后。如果你选择仅必要 Cookie，它就一直关着。 如果你选了接受统计又想反悔，用下面的按钮：选择会立即反转， 下次访问时脚本就不会加载了。

Cookie 与 localStorage

本站不设置任何 Cookie。它唯一存储的东西，是你浏览器 localStorage 里的一条记录。 localStorage 是按站点隔离的存储区，不像 Cookie 那样会随请求发给服务器：

coordcalc-consent granted 或 essential 记住你对同意横幅的回答，免得在每个页面反复询问。

以上就是完整清单。没有会话标识符、没有偏好设置存储，也没有任何形式的第三方存储。 清除浏览器中本站的站点数据即可删除这个键，横幅会在你下次访问时再问一次。

被嵌入的计算器

计算器可以用 embed=1 嵌入到别的网站，详见 开发者指南。被嵌入的计算器只会更私密，不会更差： 框架内不显示横幅，统计脚本也永不加载，因为同意的决定权属于承载嵌入的那个网站。 被嵌入的工具在加载完成后不发出任何请求、不写入任何存储，也不读取它周围页面的任何内容。

我们没有的数据

因为没有账号、没有邮件订阅、没有评论框，本站不持有任何人的姓名、邮箱地址、 通信地址或电话号码。没有用户名单可供泄露、出售或移交，也没有办法把一次计算与某个人关联起来。 如果监管方或收购方索要本站访客的个人数据，诚实的回答是：一份都没有。

本站不卖数据、不出租数据，也不与广告联盟、数据经纪商或社交平台共享数据。没有什么可共享的。

你的选择与权利

拒绝统计并不影响你在本站做任何事，这也正是多数隐私监管机构本来就倾向的立场。除此之外：

  • 随时更改同意状态，用上面的按钮即可。
  • 删除已存储的选择，在浏览器中清除本站的站点数据即可。
  • 彻底拦截该脚本，任何内容拦截工具都行；没有它，所有计算器都能正常工作。
  • 有任何疑问都可以问，通过下方的联系方式提出，你会得到真人回复，而不是模板回信。

在隐私法赋予你查阅、更正或删除权利的场合，这些权利在本站是轻而易举就能满足的： 唯一可能与你有关的记录，是一条匿名日志或一个匿名统计事件，而两者之中都没有任何能追溯到你本人的标识。 使用本站所适用的条款见使用条款。

本政策的变更

如果本站将来增加了收集内容超出本页所述的东西——账号体系、邮件订阅、换一家统计服务商—— 本页会先被重写，顶部的日期也会随之改变。实质性变更会在站内公告，而不是埋在这里。
