Privacy policy

Last updated 9 October 2026 Applies to every page on this site

This site is a set of calculators, and the shortest honest summary of its privacy position is this: the calculators run on your device, and the numbers you put into them stay on your device. There is no account, no form, no upload and no server-side calculation. This page explains the small number of exceptions — a web server log, an opt-in analytics script and one localStorage key — in the same plain language the rest of the site uses.

The short version

  • Coordinates, values and pasted lists never leave your browser. Every conversion, adjustment, area and volume is computed by JavaScript running on your machine. There is no API call behind the calculator and no server that sees your input.
  • No advertising, no ad networks, no cross-site tracking. No third-party advertising or social script loads on any page.
  • Analytics is opt-in and cookieless. A single analytics script may load, and only after you press Accept analytics. It records page views and which tool was used. It sets no cookie and builds no profile that follows you.
  • One localStorage key. The only thing written to your browser is coordcalc-consent, which remembers the choice you made in the banner. You can delete it at any time.
  • The web server keeps ordinary logs. Any web server does: your IP address, the page requested, the time, and your browser's user agent. Those logs are for operating and securing the site, not for profiling.

What never leaves your browser

Everything you type into a calculator is processed by the page you have already loaded. The transverse Mercator series, the Vincenty distance routine, the least-squares traverse adjustment, the shoelace area sum and the DXF file parser are all JavaScript inside the document. When you convert 43.642567, -79.387139 to a UTM grid reference, or read the vertices out of a CAD file, the data is read from a local file input or a textarea and written back into the same page.

There is no point in the flow at which your input is serialised and sent anywhere. You can confirm this yourself: open your browser's developer tools, watch the network tab, and use any calculator. After the page and its stylesheet and scripts have loaded, using the tools produces no requests at all. The calculators also work offline once the page is open, which is only possible because nothing round-trips to a server.

Files are the same. The DXF coordinate extractor reads the file you pick with the browser's own FileReader interface, entirely in memory. The file is not uploaded, queued or stored, and closing the tab discards it.

What the web server sees

To deliver this page at all, a web server has to answer your request. That produces a log entry, as it does on every site: the requested URL, the date and time, your IP address, the page you came from if your browser sends one, and your browser's user-agent string. This is standard, unavoidable and not something this site adds.

Those logs are used to keep the site working — error rates, broken links, abusive traffic — and are not combined with anything you do inside a calculator, because the site never receives what you do inside a calculator. Logs are retained for a bounded period and then deleted.

Analytics, and the consent banner

The site uses a privacy-respecting analytics script to learn which calculators are used and which are ignored, so that effort goes where it is useful. The script is cookieless: it does not set a cookie, does not read an existing one, does not fingerprint your device, and does not follow you to any other site. It records the page name, the event (a page view, that a calculator was used, that an outbound link was clicked) and coarse properties such as the referrer.

It loads only if you accept. The banner at the bottom of the page offers two choices:

ChoiceWhat happens
Accept analytics The analytics script loads on this and later visits. Page views and tool-use events are counted. Nothing you type into a calculator is included — the event says that a tool was used, not what you converted.
Essential only The analytics script never loads, on this and later visits. The site works identically; you simply tell us nothing.

Until you choose, no analytics request is made at all — the gate is closed before the script has a chance to load, not after. If you choose Essential only it stays closed. If you choose Accept analytics and change your mind later, use the button below: the choice is reversed immediately and the script will not load on your next visit.

Cookies and localStorage

This site sets no cookies. The one thing it stores is a single entry in your browser's localStorage, which is a per-site storage area that is never sent to a server with a request the way a cookie is:

KeyValuePurpose
coordcalc-consent granted or essential Remembers your answer to the consent banner so it does not ask again on every page.

That is the complete list. There is no session identifier, no preference store and no third-party storage of any kind. Clearing your browser's site data for this domain removes the key, and the banner will simply ask again the next time you visit.

Embedded calculators

The calculators can be embedded in another site with embed=1, as described in the developer guide. An embedded calculator is more private again, not less: the banner is not shown inside a frame, and the analytics script never loads there, because the consent decision belongs to the site that hosts the embed. An embedded tool makes no request of any kind after it loads, sets no storage, and reads nothing from the page around it.

Data we do not have

Because there is no account, no newsletter and no comment form, this site holds no name, no email address, no postal address and no phone number for anyone. There is no user list to leak, sell or hand over, and no way to link a calculation to a person. If a regulator or a purchaser asked for the personal data of this site's visitors, the honest answer would be that none is held.

The site does not sell data, does not rent it, and does not share it with advertising networks, data brokers or social platforms. There is nothing to share.

Your choices and rights

You can do everything on this site with analytics refused, which is the position most privacy regulators would prefer anyway. Beyond that:

  • Change your consent at any time with the button above.
  • Delete the stored choice by clearing site data for this domain in your browser.
  • Block the script entirely with any content blocker; every calculator works perfectly without it.
  • Ask a question about any of this through the contact address below, and you will get an answer from a person rather than a form letter.

Where privacy law gives you rights of access, correction or erasure, those rights are trivially satisfied here: the only record that could concern you is an anonymous log line or an anonymous analytics event, and there is no identifier in either that could be traced back to you.

Changes to this policy

If the site ever adds something that collects more than this page describes — an account system, a newsletter, a different analytics provider — this page will be rewritten first and the date at the top will change. Material changes will be announced on the site itself rather than buried here.
