Frequently asked questions

What is CoordCalc?

CoordCalc is a collection of free browser-based calculators for surveying, GIS and civil engineering work — coordinate conversion, distance and bearing, land area, slope and elevation, map scale, and professional traverse and curve calculations.

Are these surveying calculators free to use?

Yes. Every calculator is free, with no account, no login and no usage limit. The calculations run entirely in your browser, so your data is never uploaded.

Which coordinate systems are supported?

Geographic latitude and longitude in decimal degrees, DMS and DDM; the UTM / WGS84 projected grid; and the MGRS military grid reference system. Coordinate reference system parameters are stated on each tool page.

Can I use these tools on a phone in the field?

Yes. Every calculator is responsive and mobile-first. Once a page has loaded, the calculation continues to work without a network connection.

How accurate are the calculations?

All tools use double-precision arithmetic and state their assumptions on each page. Coordinate conversion uses the WGS84 ellipsoid by default. For critical setting-out work, verify results against your project's declared coordinate reference system.

Which coordinate systems and datums are supported?

Geographic latitude and longitude on WGS84 in decimal degrees, DMS and DDM; the UTM and MGRS grids; and all 134 NAD83 State Plane zones across the 50 states, in metres, US survey feet or international feet. Each tool page states its ellipsoid, datum and rounding.

Is there a batch or API option for professional use?

The free calculators handle single values. Batch processing and API access for traverse and curve calculations are planned for professional users who need to process many coordinates at once.
